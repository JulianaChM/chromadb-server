# **App Name**: CodeBlueAI

## Core Features:

- Intelligent Dispatch Engine: Generative AI tool that analyzes emergency descriptions and locations to reason through and suggest the most appropriate hospital based on current capacity and specialized care requirements.
- Emergency Command Dashboard: A high-visibility responsive interface displaying real-time metrics for active emergencies, ambulance status, and hospital availability.
- Live Dispatch Map: Integration with Google Maps API to visualize routes from patient locations to the recommended healthcare facilities with traffic-aware updates.
- Smart Protocol Chatbot: AI-powered assistant tool providing immediate medical protocol guidance and operational checklists during critical moments.
- Resource Management: Unified system to manage fleet (ambulances) and facility (hospital) attributes and occupancy rates.

## Style Guidelines:

- A clean, 'Light' color scheme centered around 'Clinical Precision'. The primary color is a Deep Azure (#1565C0), chosen for its psychological associations with trust and hospital environments.
- The background color is a heavily desaturated variant of the primary (#F5F8FA) to provide a spacious, sanitary feel. The accent color is an Analogous Sky Blue (#0288D1) for focused interactions and iconography.
- Font pairing: 'Space Grotesk' for high-precision technical headlines and 'Inter' for body text and data grids, ensuring readability and an objective, machined look.
- Responsive dashboard design optimized for 'Crisis Environments', featuring high-contrast card components and skeleton loaders to reduce perceived latency.
- Functional motion with micro-interactions on emergency status changes and subtle pulse animations for critical priority items.
- Strict, geometric medical icons utilizing 'Rojo emergencia' (#D32F2F) only for active life-threatening incidents to ensure immediate visual triage.
